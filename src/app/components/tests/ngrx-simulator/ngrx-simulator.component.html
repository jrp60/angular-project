Esta simulación representa visualmente el ciclo de flujo de datos de una arquitectura basada en NgRx en Angular.

Cada nodo es una etapa del ciclo ( Store, Reducer, Effects...). El estado actual del flujo se guarda haciendo uso de la store

Cada vez que se pulsa el botón Next Step, se despacha una acción que dispara un effect, y este va avanzando el progreso visual mediante una animación.

El ciclo se repite automáticamente una vez se completan todos los pasos, mostrando cómo fluye la información de forma reactiva.
