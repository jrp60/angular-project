This simulation visually represents the data flow cycle of an Angular architecture based on NgRx.

Each node represents a stage in the reactive flow (Store, Reducer, Effects...). The state of the simulation is managed centrally through the Store.

When the Next Step button is clicked, an action is dispatched, triggering an effect. The effect simulates an asynchronous process with a visual delay, gradually advancing the flow between nodes.

Below the simulation, a text panel slides in from the bottom to describe each step. As the next step begins, the current explanation fades upward and is replaced by the next — in sync with the flow of data.

The app uses selectors to extract state, reducers to compute state changes immutably, and effects to handle asynchronous side effects — all coordinated via the Store.
